# Repo instructions for Claude Code

## Writing standards (mandatory)

All prose you write or edit in this repository — `README.md`,
`GetStarted.md`, `PATTERNS.md`, any lab's `RESULTS.md`, `Contributing.md`,
the `Quickstart*.md` files, and any new documentation — must follow
[`WRITING_STANDARDS.md`](./WRITING_STANDARDS.md). That file defines the
house style (a hybrid of ASD-STE100 and ISO 24495-1) and includes a
ready-to-use prompt block. Load it before drafting or revising documentation
and apply its rules to every sentence you write, not only to new files.

This does not apply to code comments or commit messages.

## Skill

`SKILL.md` defines the perf-ninja lab runner skill (build, validate,
benchmark, and document every lab). Its `RESULTS.md` template and
`PATTERNS.md` aggregation step are written under the writing standards
above — follow both files together when running that skill.
